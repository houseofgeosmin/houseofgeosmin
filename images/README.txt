PROJECT PHOTOS GO IN THIS FOLDER
=================================

Make one folder per project, for example:

  images/project-1/cover.jpg   <- the picture shown on the project card
  images/project-1/1.jpg       <- photos shown inside the pop-up
  images/project-1/2.jpg
  images/project-1/3.jpg

  images/project-2/cover.jpg
  ...and so on.

Tips:
- Use small lowercase names with no spaces (cover.jpg, 1.jpg, living-room.jpg).
- Resize photos to about 1600 pixels wide and keep each under 400 KB (squoosh.app does this free).
- The names here must match exactly what you write in projects.js.

Full step-by-step instructions are in EDITING-GUIDE.md.
